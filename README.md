# OmniBrowser Android

تطبيق متصفح وتنزيل وترجمة فيديو مبني باستخدام Kotlin وJetpack Compose.

## المكونات الرئيسية

- متصفح WebView مع تبويبات عادية وخفية.
- حفظ حالة التبويبات أثناء جلسة التطبيق.
- شريط تبويبات أفقي مع favicon وحالة التحميل.
- تنزيلات خلفية عبر WorkManager وForeground Service.
- استئناف التنزيلات وإظهار إشعارات التقدم.
- التقاط الصوت الداخلي عبر AudioPlaybackCapture على Android 10+.
- تعرف صوتي متدفق عبر Vosk، مع استخدام النتائج المرحلية داخليًا فقط.
- عرض ترجمة الجمل المكتملة عبر ML Kit المحلي أو المزود عبر الإنترنت.
- مشغل داخلي للفيديوهات المحلية والمكتملة التنزيل.
- دعم ملفات SRT وVTT وإدارة الملفات الأساسية.

## المتطلبات

- Android Studio حديث.
- Java 21.
- Android SDK وBuild Tools المناسبان للمشروع.
- Compile SDK 36.1 وTarget SDK 34.
- Android 10+ لميزة التقاط الصوت الداخلي.

## تشغيل المشروع

1. فك ضغط المشروع وافتح المجلد الذي يحتوي على `settings.gradle.kts` في Android Studio.
2. اسمح لـ Gradle بمزامنة الاعتمادات.
3. أنشئ ملف `.env` محليًا عند الحاجة، اعتمادًا على `.env.example`، ولا ترفع المفاتيح السرية إلى GitHub.
4. شغّل `assembleDebug` أو ثبّت التطبيق على جهاز Android للاختبار.

## أوامر البناء

```bash
gradle :app:assembleDebug
gradle :app:testDebugUnitTest
```

## المزامنة مع GitHub

بعد إجراء تغييرات محلية:

```bash
git add -A
git commit -m "Describe the change"
git push origin main
```

المستودع المقترح لهذا المشروع خاص. لا تتم مزامنة مجلد Sandbox تلقائيًا بشكل دائم؛ يجب تنفيذ `git add/commit/push` عند الحاجة، أو تشغيلها من جهاز تطوير ثابت.

## ملاحظات الخصوصية

- لا ترفع `.env` أو مفاتيح التوقيع أو كلمات المرور.
- ملف `debug.keystore` مستبعد من Git عبر `.gitignore`.
- ملفات البناء والكاش مستبعدة لتقليل حجم المستودع.
- يجب احترام شروط استخدام المواقع وحقوق أصحاب المحتوى عند تنزيل أي ملف.
